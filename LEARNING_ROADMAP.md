# Six-Semester Learning Roadmap

**Degree:** B.Tech AI & ML  
**University:** K.R. Mangalam University  
**Career Interests:** Artificial Intelligence & Machine Learning, Cybersecurity

## Semester 1 – Foundations
- Learn Python fundamentals and problem-solving
- Understand Linux, Git and GitHub
- Study basic programming and mathematics
- Complete university lab assignments

**Target:** Build a strong programming foundation.

## Semester 2 – Core Programming
- Improve Python and learn C/C++ fundamentals
- Study data structures and algorithms
- Learn SQL and database basics
- Practise coding problems regularly

**Target:** Solve beginner and intermediate programming problems.

## Semester 3 – AI & Security Basics
- Learn statistics and probability for ML
- Study machine learning fundamentals
- Understand computer networks and operating systems
- Practise cybersecurity concepts in legal learning environments

**Target:** Complete one beginner AI project and one security-focused lab project.

## Semester 4 – Practical Projects
- Learn data preprocessing and model evaluation
- Explore web development and APIs
- Study ethical hacking fundamentals and secure coding
- Contribute to GitHub projects

**Target:** Build and document two portfolio projects.

## Semester 5 – Specialisation
- Explore deep learning and neural networks
- Study cybersecurity tools and defensive security
- Learn cloud and deployment fundamentals
- Prepare for internships and technical interviews

**Target:** Complete a substantial AI/ML or cybersecurity project.

## Semester 6 – Career Preparation
- Refine portfolio and resume
- Practise DSA and interview questions
- Apply for internships
- Review projects and document achievements

**Target:** Have a strong portfolio and be internship-ready.

## Progress Review
Review this roadmap at the end of every semester and update goals based on coursework, projects and interests.
